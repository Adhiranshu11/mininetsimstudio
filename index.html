Mini NetSim Studio

A small simulator for learning how packets find their way through a network. Build a topology, choose two computers and see the shortest route, hop count and delay.

Team

Project members.

What it does

  • Add computers and routers, then connect them with links that have a latency in ms.
  • Send a packet between two computers and watch it travel hop by hop.
  • Find the shortest route with Dijkstra's algorithm, using link latency as the cost.
  • Show the route, hop count and simulated delay, with every step of the algorithm in a table.

How the delay is calculated

  • Link delay is the sum of the latency on every link in the route.
  • Each router the packet passes through adds 2 ms of processing time.
  • Total delay = link delay + 2 ms × number of routers on the path.
  • Hop count is the number of links crossed. The fewest hops is not always the lowest delay.

Dijkstra's algorithm as used here

dist[all] = ∞ ; dist[source] = 0
repeat until every reachable device is settled:
    u = unsettled device with the smallest dist
    mark u as settled
    if u is the destination: stop
    if u is a computer and not the source: continue   (hosts do not forward)
    for each neighbour v of u:
        if dist[u] + latency(u,v) < dist[v]:
            dist[v] = dist[u] + latency(u,v) ; previous[v] = u
path = follow previous[] back from the destination

Time complexity O(V²) with a simple array scan, where V is the number of devices. Built with plain HTML, CSS and JavaScript, with the topology drawn in SVG.
